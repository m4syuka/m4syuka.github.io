# Инструкции для следующих LLM по созданию постов

## Общая концепция блога
- Название: **Просто блог**
- Темы: аналоговая (плёночная) фотография + программирование
- Стиль: Web 1.0 (ретро, минимализм, monospace-шрифты, простые границы, двойные линии)
- Язык: **только русский**
- Каждый пост — **отдельный HTML-файл** в папке `posts/`
- Имя файла: `YYYY-MM-DD-nazvanie-translitom.html`

## Структура нового поста (обязательно)
1. Полный валидный HTML5 документ
2. Подключение `../style.css`
3. Такой же `<header>` с ссылкой на главную, как в существующих постах
4. `<article>` с заголовком, датой, текстом, изображениями и тегами в конце
5. Кнопка переключения режима (использовать тот же script.js)
6. Ссылка «← Вернуться на главную» перед футером

## Frontmatter-подобная информация (внутри HTML)
- Дата в формате «12 января 2025»
- 4–6 тегов в формате `#тег` (использовать те же классы `.tag`)
- Хотя бы одно фото (можно использовать https://picsum.photos/id/XXX/800/500)


## Для LLM, которые будут получать .md
Когда пользователь пришлёт текст в формате Markdown, ты должен:
1. Не менять текст 
2. Преобразовать в полный HTML-пост по шаблону выше
3. Добавить подходящие теги

## Файлы-помощники
- `templates/POST_TEMPLATE.html` — будет создан позже как чистый шаблон
- Используй существующие посты как пример стиля и оформления

Готовь новые посты в том же духе — минималистично, атмосферно и по делу.
